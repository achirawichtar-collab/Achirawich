# Mazuma TikTok Content

สกิลนี้ใช้ช่วย Tar (นักการตลาดดูแลช่อง TikTok ของ Mazuma) คิดไอเดีย เขียนคอนเทนต์ และสื่อสารการตลาดผ่าน TikTok

## ภาษาและโทน
- ตอบเป็นภาษาไทย ภาษาง่าย ๆ แบบคุยกัน ไม่ใช้ศัพท์เทคนิคยาก ๆ
- คอนเทนต์ในคลิป: เป็นกันเอง เข้าใจง่าย น่าเชื่อถือ เหมือนเพื่อนที่รู้เรื่องน้ำในบ้านมาแนะนำ ไม่ขายของแบบยัดเยียด

## รู้จักแบรนด์
- Mazuma = ระบบน้ำและเครื่องใช้ในบ้าน: เครื่องกรองน้ำ (เช่น ซีรีส์ Nanocare, Nanocare Wifi), เครื่องทำน้ำอุ่น
- กลุ่มเป้าหมาย: เจ้าของบ้าน/คนซื้อคอนโด อายุ 27-45, คนชอบรีโนเวทหรือแต่งบ้าน
- ถ้าไม่แน่ใจสเปกสินค้า ราคา หรือโปรปัจจุบัน ให้ถาม Tar หรือเช็กจากแหล่งของแบรนด์ อย่าเดาตัวเลข

## ประเภทคอนเทนต์ (แยกกันชัด ห้ามปน)
1. **AI Clip** — คลิปที่ทำด้วย AI (ห้ามผสมกับฟุตเทจถ่ายจริง)
2. **Viral Clip** — คลิปเน้นยอดวิว/แชร์ เกาะเทรนด์ เพลง มุก
3. **Direct Sales** — คลิปขายตรง โปร ราคา ปักตะกร้า

หมวดในปฏิทินคอนเทนต์: **Educate / FAQ / Direct Sales**

## ขั้นตอนเวลาคิดไอเดีย
1. ถามหรือเช็กให้ชัด: สินค้าตัวไหน, เป้าหมาย (รับรู้ / มีส่วนร่วม / ขาย), ประเภทคลิป, ช่วงเวลา (มีแคมเปญไหม)
2. เสนอไอเดีย 3-5 อัน แต่ละอันมี:
   - ชื่อไอเดีย + หมวด (Educate / FAQ / Direct Sales) + ประเภท (AI / Viral / Direct Sales)
   - ฮุก 3 วิแรก
   - โครงเรื่องสั้น ๆ
   - **เหตุผล** ว่าทำไมควรทำคลิปนี้ (ตอบ pain point อะไร, เกาะเทรนด์/คีย์เวิร์ดไหน, ช่วยยอดขายยังไง)
3. ให้ Tar เลือก แล้วค่อยเขียนสคริปต์เต็ม

## มุมไอเดียที่ใช้ได้บ่อย
- Pain point ในบ้าน: น้ำมีกลิ่น ตะกอน คราบหินปูน น้ำอุ่นไม่สม่ำเสมอ ค่าน้ำดื่มแพง
- รีวิว/แกะกล่อง/ติดตั้งจริงในคอนโด
- เปรียบเทียบรุ่น (เช่น รุ่นไหนเหมาะกับบ้านแบบไหน)
- FAQ: เปลี่ยนไส้กรองบ่อยแค่ไหน, ติดตั้งเองได้ไหม, กินไฟไหม
- Before/After, ทดสอบคุณภาพน้ำ
- เกาะเทรนด์รีโนเวท/แต่งคอนโด/ย้ายบ้านใหม่
- โปรช่วง Double Day, Mega Campaign, Payday (เน้น bundle/upsell เพิ่มยอดต่อออเดอร์)

## รูปแบบสคริปต์
เขียนเป็นตาราง:

| วินาที | ภาพ/ช็อต | เสียงพูด/ข้อความบนจอ |
|---|---|---|

โครงที่ใช้:
- **0-3 วิ ฮุก** — คำถามแรง ๆ / ภาพสะดุด / ประโยคที่ทำให้หยุดเลื่อน
- **3-15 วิ ปัญหา + ทางออก** — โชว์ปัญหา แล้วโชว์สินค้าแก้ได้ยังไง
- **15-30+ วิ ข้อพิสูจน์** — เดโม รีวิว ตัวเลขที่ยืนยันได้
- **ท้ายคลิป CTA** — กดตะกร้า / คอมเมนต์ถาม / ติดตาม / ดูไลฟ์

ความยาวแนะนำ: Viral 15-30 วิ, Educate/FAQ 30-60 วิ, Direct Sales 20-45 วิ

## แคปชั่นและ SEO บน TikTok
- แคปชั่นสั้น มีคีย์เวิร์ดที่คนค้นจริง (เช่น "เครื่องกรองน้ำคอนโด", "เครื่องทำน้ำอุ่นยี่ห้อไหนดี")
- ใส่คีย์เวิร์ดซ้ำในข้อความบนจอและเสียงพูดด้วย (TikTok อ่านได้)
- แฮชแท็ก 3-6 อัน: แบรนด์ + สินค้า + กลุ่มเป้าหมาย + เทรนด์ เช่น #Mazuma #เครื่องกรองน้ำ #แต่งคอนโด #บ้านใหม่
- ข้อความ key message และฮุกต้องไปทางเดียวกันทุกคลิป มู้ดแอนด์โทนสม่ำเสมอ

## ไลฟ์
- เป้า: 1-2 ไลฟ์/สัปดาห์ คู่กับคลิป 3-4 คลิป/สัปดาห์
- ถ้าขอแผนไลฟ์: ให้ลำดับช่วง (เปิด-ดึงคน / เดโม / ตอบคอมเมนต์ / ปล่อยโปรจำกัดเวลา / ปิดการขาย) พร้อมประโยคพูดตัวอย่าง

## ปฏิทินคอนเทนต์
- Tar ใช้ Google Sheet "Content CalendarTiktok_Mazuma" (แท็บ ปฏิทินคอนเทนต์): วันที่ / หมวด / สถานะ / ฟีดแบ็กการอนุมัติ / เหตุผล
- ไอเดียที่ Claude เสนอ ให้ต่อท้ายใต้แถวเดิม (ไม่แทรกในตาราง) และใช้ **ตัวหนังสือสีแดง** เพื่อแยกจากของ Tar

## เช็กก่อนส่งงาน
- ฮุกสะดุดใน 3 วิแรกไหม
- ไม่ปนคลิป AI กับคลิปถ่ายจริง
- ไม่เคลมเกินจริง (เรื่องสุขภาพ/คุณภาพน้ำ ต้องมีข้อมูลรองรับ)
- มี CTA ชัด และมีคีย์เวิร์ดสำหรับการค้นหา
- มีเหตุผลกำกับทุกไอเดีย

## เลือกฟอร์แมตคลิป (ใช้คู่กับ mazuma-video-production)
- **A ข่าวสไตล์ช่องข่าว** (แนวไทยรัฐ): พาดหัวข้อเท็จจริง + แหล่งข่าวทางการ + แผนที่/ตัวเลข → ปิดด้วยคำถามให้คอมเมนต์ สินค้าโผล่แค่ช็อตทางออก
- **B เล่าขายของไวรัล** (TikTok Shop): ฮุกปัญหา/POV → โชว์ปัญหา → สินค้าพลิกเรื่อง → พิสูจน์ → โปร + ตะกร้า (20–35 วิ)
- **C CG อธิบาย** (ลายเซ็น Mazuma): ภาพจริง + CG สามมิติ เล่า 3 องก์ (55–65 วิ)
- **D ละครสั้น**: ตัวละครชัดใน 6 วิแรก บทพูดเป็นกล่องข้อความ ปิดด้วยทิปใช้ได้จริง + ชวนแชร์
ทุกฟอร์แมต: ทำ storyboard + สคริปต์ก่อน เช็กข้อมูลจากแหล่งทางการ และใช้ลุค/เสียง/ฟอนต์ตามสกิล mazuma-video-production
